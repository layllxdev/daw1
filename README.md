# 🌐 Desenvolvimento de Aplicações Web

Repositório criado para organizar meus estudos e atividades da disciplina de **Desenvolvimento de Aplicações Web (DAW)** durante a graduação em **Análise e Desenvolvimento de Sistemas**.

Aqui estão reunidos exercícios, atividades realizadas em sala e práticas de desenvolvimento utilizando principalmente **HTML, JavaScript e recursos da Web**.

## 📚 Conteúdos

### 📝 Atividades

Exercícios desenvolvidos durante a disciplina para praticar os fundamentos do desenvolvimento de páginas Web.

* Estrutura de páginas HTML
* Elementos e tags HTML
* Parágrafos
* Cabeçalhos
* Imagens
* Hiperlinks
* Links internos e externos
* Navegação entre páginas
* Organização de conteúdo

### 🏫 Atividades em sala

Exercícios desenvolvidos durante as aulas da disciplina, incluindo diferentes práticas de HTML e JavaScript.

Entre os conteúdos trabalhados:

* Estrutura HTML
* Elementos de texto
* Imagens
* Hiperlinks
* Formulários e interação
* Manipulação de páginas
* JavaScript
* Consumo de dados

### 🐶🐱 HTML — Hiperlinks e imagens

Uma das atividades trabalha a criação de páginas utilizando **hiperlinks, imagens e navegação entre diferentes páginas**.

O projeto contém páginas relacionadas a:

* 🐶 Cachorros
* 🐱 Gatos
* 🔗 Hiperlinks externos
* 🔗 Hiperlinks internos
* 🔗 Hiperlinks locais

Também foram utilizadas imagens para complementar as páginas e praticar a organização de arquivos e diretórios em projetos Web.

### 👥 Projeto de usuários

O repositório também contém uma atividade utilizando **HTML e JavaScript** para trabalhar com dados de usuários.

A atividade utiliza um arquivo JavaScript para realizar a busca de dados e apresentar as informações na página.

Conceitos trabalhados:

* JavaScript
* `fetch()`
* JSON
* Manipulação do DOM
* Eventos
* Exibição de dados em HTML

### 🏃‍♀️ Dados

O projeto também possui um arquivo JSON relacionado a uma tabela de resultados de corrida:

`resultado-corrida-tabela-girl-power.json`

Esse arquivo foi utilizado como parte das atividades de manipulação e organização de dados.
